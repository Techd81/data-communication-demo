# 数据通信网络 · 智能全流程演示系统

面向数据通信方法研究的交互式网页演示系统，完整呈现「发送方 → 信道 → 接收方」全链路流程：
动态密钥派生 → AES 加密 → 分块 → 自适应编码 → 多路径传输 → 差错恢复 → 完整性校验 → 排序重组。
**所有算法均真实运行，绝非动画模拟**，参数可调、过程可观察、结果可验证。

## 核心算法

### 1. 动态密钥派生

根据数据重要性 `I`（1-5）与安全指标 `S`（0-1）实时派生会话密钥：

```
K = SHA-256(I, S, T)
```

`T` 为时间因子，保证每次会话密钥独立，密钥哈希实时展示。

### 2. AES-128-GCM 对称加密

对数据块进行真实加解密，输出密文与 IV，机密性与完整性认证一体完成（Web Crypto API）。

### 3. 自适应编码决策

根据实时网络参数动态切换编码方案：

| 网络条件 | 编码方案 |
| --- | --- |
| 带宽 `B ≥ 8 Mbps` 且丢包率 `L ≤ 5%` | **Huffman 高效编码**，压缩后长度 `L2 = L1 × r1` |
| 其余情况 | **RS 容错编码**，总符号数 `n_total = n_d + n_r`（冗余 `n_r` 可调 32-128） |

### 4. Huffman 编码 / 解码

基于字符频次重建前缀树的无损压缩。往返编解码完全一致，压缩率可达 **0.55**。

### 5. RS 纠删码（Reed-Solomon）

基于 GF(256) 有限域的系统化编码，配合伴随式方程求解实现擦除恢复：

- RS(255, 159)：跨组擦除 80+ 符号可完整恢复
- 单组擦除 ≤ 96 符号恢复成功；超出纠错容量正确判定失败

### 6. 多路径传输与动态重路由

数据块沿三条可用路径并行传输，实时监测路径质量：

- 时延 `D_k` 超过阈值 `D_th` 即判定路径劣化
- 路径概率以 `Δp = 0.1` 步进调整，劣化路径上的数据块自动重路由至健康路径

### 7. 差错控制

丢包触发超时重传机制：

```
T_timeout = α × RTT = 75ms
```

超时后产生错误报告并重传；RS 模式下丢失符号由伴随式方程直接恢复。

### 8. 完整性校验与重组

- 逐块哈希对比：`H_received ≟ H_original`
- 分块守恒：`Σs_i = |P|`
- 按序列号排序重组数据包，解密 + JSON 还原输出最终数据

## 快速开始

无需构建工具，任意静态服务器即可运行：

```bash
cd 演示系统
python -m http.server 8747 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8747/index.html
```

也可直接双击 `演示系统/index.html` 以 `file://` 协议打开
（Chrome / Edge / Firefox 对本地文件均视为 Web Crypto 安全上下文）。
