3核心算法 · 数学化表达
A1

动态密钥生成

K = H(I, S, T)

I ∈ [1,5] 数据重要性；S 网络安全性综合指标；T 时间戳。达到次数 N 或间隔 Δt 自动更新。

A2

AES 数据加密

C = E(K, Djson)

E 为加密函数，Djson 为标准化明文，K 为动态密钥，C 为加密数据包。

A3

Huffman 高效编码

L2 = L1 × r1

带宽充足且丢包率低时采用，r1 为压缩率，L1/L2 为编解码前后长度。

A4

RS 容错编码

ntotal = nd + nr

网络状况较差时采用，nr 个冗余符号，丢失不超过 nr/2 个符号即可恢复。

A5

数据分块

Σ si = |P|

编码后数据包 P 分割为 {B1…Bn}，每块携带唯一 ID 与序列号 SN。

A6

多路径概率调度

Σ pij = 1

数据块 Bi 选择路径 Pathj 的概率为 pij；故障切换：pil += Δp，pik −= Δp。

A7

路径故障判定

Dk > Dth 或 Tk < Tth

监测路径延迟 Dk 与吞吐量 Tk，超过设定阈值即判定故障或拥塞。

A8

完整性哈希校验

Hreceived ≟ Horiginal

接收端重算数据块哈希，与发送端附带原始哈希对比，相等则完整，否则判定损坏。

A9

排序重组与解密

Precovered = Sort({Bi | SNi})
Drecovered = D(K, Precovered)

按序列号排序恢复数据包，使用对应密钥解密还原原始数据。

A10

格式还原

Dfinal = frestore(Drecovered)

将解密后的数据转换回原始格式，供用户使用。

A11

超时重传

Ttimeout = α · RTT

α 为调整系数（可取 1.5），RTT 为网络往返时间；超时未收到即标记丢失并请求重传。

A12

异常处理优先级

丢失 > 解密失败 > 还原失败

错误报告按优先级处理，设置最大重试次数，避免无限重传，超限后终止并上报高层。
