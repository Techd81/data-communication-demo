# 数据通信网络 · 智能全流程演示系统

基于《一种数据通信网络的数据通信方法及系统》构建的高交互网页演示系统，
完整覆盖数据通信全流程的全部技术环节，所有算法均可真实运行。

界面遵循 **Hand-Drawn Sketch（手绘涂鸦）风格**：纸面点阵背景、粉彩便签卡片、墨色手写笔迹（马善政楷书 / Caveat）、略微歪斜的边框与硬边纸片投影，弹性动效（300–500ms spring 缓动：悬停抬起·旋转·按压收回）。

## 快速启动

无需构建工具，任意静态服务器即可运行（推荐方式）：

```bash
cd 演示系统
python -m http.server 8747 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8747/index.html
```

也可直接双击 `index.html` 以 `file://` 协议打开（Web Crypto 需浏览器安全上下文，
Chrome / Edge / Firefox 对本地文件均视为安全上下文）。

## 实时演示 · 操作指南

### 参数调节
- **数据内容**：可编辑 JSON 输入（默认订单数据）
- **重要性 I**（1-5）：影响动态密钥 K = H(I, S, T)
- **安全指标 S**（0-1）：同上参与密钥派生
- **带宽 B**（2-20 Mbps）与**丢包率 L**（0-30%）：驱动自适应编码决策
  - B ≥ 8 Mbps 且 L ≤ 5% → **Huffman 高效编码**
  - 否则 → **RS 容错编码**（冗余 n_r 可调 32-128 符号）
- **可用路径**：点击 Path 1/2/3 循环切换 正常 → 拥塞 → 故障，实时观察路径概率
  调整（Δp=0.1）与数据块自动重路由
- **演示速度**：0.5×-3× 调节节奏

### 控制按钮
- **开始传输 →**：自动播放完整流程（S1 预处理 → S2 编码传输 → S3 接收恢复）
- **单步 →**：逐步执行，每步暂停等待继续
- **重置 ↺**：清空日志与画布
- **循环 ↻**：完成后自动重播

### 演示看点
1. **动态密钥**：K = SHA-256(I, S, T) 实时计算，展示密钥哈希
2. **AES 加密**：真实 AES-128-GCM 加密，密文长度与 IV 展示
3. **自适应编码**：根据实时网络参数切换 Huffman / RS，公式 L2=L1×r1 或
   n_total=n_d+n_r 如实演算
4. **分块**：数据包分割为 B1…Bn，各带唯一 ID 与序列号，Σs_i = |P|
5. **多路径传输**：Canvas 纸面点阵动画展示数据块沿三条手绘曲线路径流动、方向箭头指示；
   点击路径模拟故障，观察 D_k > D_th 判定、概率调整与重路由弧线
6. **异常处理**：丢包 → 超时 T_timeout = α·RTT = 75ms → 错误报告 → 重传；
   RS 模式下丢失符号经伴随式方程直接恢复
7. **完整性校验**：H_received ≟ H_original 逐块哈希对比
8. **排序重组**：按序列号恢复数据包，解密 + JSON 还原展示最终结果

## 技术实现

- **纯原生实现，零依赖**：HTML5 + CSS3 + Canvas + Web Crypto API
- **真实算法**：
  - Huffman 编码 / 解码（频次表重建前缀树）
  - RS 纠删码（GF(256) 有限域，系统化编码 + 擦除恢复伴随式方程求解）
  - AES-128-GCM 加解密（SHA-256 派生动态密钥）
- **响应式**：桌面 / 平板 / 移动端网格自适应

## 算法验证

核心算法均通过单元验证（node 直接运行）：

- Huffman：压缩率可达 0.55，往返解码完全一致
- RS(255, 159)：跨组擦除 80+ 符号可完整恢复；单组擦除 ≤ 96 符号恢复成功；
  超容量正确判定失败
